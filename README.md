# 🥛 Milk Diary Pro 

A professional, fully secure, and offline-first Progressive Web App (PWA) designed for dairy business owners to manage their daily milk entries, customers, expenses, and billing efficiently. 


## ✨ Key Features

* 🔒 **Military-Grade Security:** In-built App Lock (PIN), Security Questions for PIN recovery, and Tamper-Proof Checksum Backup generation.
* 🌐 **Multi-Language Support:** Seamlessly switch between **English** and **Hindi** (Pure Hindi).
* 🌓 **Dark Mode:** Built-in Dark Mode for comfortable night usage.
* 📊 **Dashboard & Analytics:** Real-time profit/expense tracking with visual charts (Powered by Chart.js).
* 📝 **Smart Daily Entry:** Morning/Evening shift management with instant Double Tick (✓✓) confirmation for saved entries.
* 📒 **Khata (Ledger) & Billing:** Auto-calculate advances/dues, generate detailed **PDF Bills**, and share directly via **WhatsApp** with professional formatting.
* 💸 **Expense Tracker:** Keep a record of daily dairy expenses (cattle feed, medicine, salary, etc.).
* ⏳ **Smart Trial & Subscription:** Built-in 60-day free trial with an advanced, hack-proof activation key system (1 Month, 1 Year, Lifetime) using SHA-256 logic.
* 📶 **Offline First (PWA):** Works 100% offline. Installable as a native app on Android/iOS via browser.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Glassmorphism & Clean UI)
* **Logic:** Vanilla JavaScript (ES6)
* **Storage:** LocalStorage API (No Backend Database Required)
* **Libraries:** `Chart.js` (for analytics), `html2pdf.js` (for PDF generation)
